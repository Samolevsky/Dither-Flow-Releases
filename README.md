# Dither Flow

Dither Flow turns images into retro, dithered graphics with 40+ classic and modern dithering algorithms, custom palettes and PNG/SVG export. Use it online at **[ditherflow.samolevsky.com](https://ditherflow.samolevsky.com)** or install the desktop app.

## Download

Get the files from the **[latest release](https://github.com/Samolevsky/Dither-Flow-Releases/releases/latest)**:

| Platform | File |
| --- | --- |
| macOS — Apple Silicon (M1 and later) | `Dither-Flow-<version>-mac-arm64.dmg` |
| macOS — Intel | `Dither-Flow-<version>-mac-intel.dmg` |
| Windows 10/11 (64-bit) | `Dither-Flow-<version>-win-x64.exe` |

On macOS, open the `.dmg` and drag **Dither Flow** to **Applications**. On Windows, run the installer; if SmartScreen warns you, choose **More info › Run anyway** (the installer isn't code-signed yet).

## Updating

Dither Flow checks for updates when it starts. You can also check any time with **Dither Flow › Check for Updates…** on macOS or **Help › Check for Updates…** on Windows. Updates download in the app and install when you restart. **Help › Release Notes** opens this page.

## Source code

This repository only hosts installers and release notes. The source code of Dither Flow isn't public.
